# 🏠 HomeMart - Furniture & Decor

HomeMart is a responsive furniture and home decor e-commerce website built using HTML, CSS, and JavaScript.

The website provides users with a simple and attractive platform to explore furniture products, view product details, manage their cart and wishlist, schedule delivery, and complete a simulated checkout process.

## ✨ Features

- 🏠 Responsive Home Page
- 🛋️ Furniture Product Listing
- 🔎 Product Details Page
- ❤️ Wishlist
- 🛒 Shopping Cart
- 🔢 Quantity Management
- 💰 Automatic Price Calculation
- 📦 Checkout System
- 📅 Delivery Date Scheduling
- ⏰ Delivery Time Selection
- 💳 Payment Method Selection
- ✅ Order Confirmation
- 💾 LocalStorage Data Management
- 📱 Mobile Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- LocalStorage
